## Интерфейсы между разработчиками

### Разработчик 1 ↔ Разработчик 2

| Что передаётся | Формат |
|----------------|--------|
| Событие от XMPP-сервиса к основному приложению | Intent с extra: task_id |
| Метод для пробуждения UI | wakeUpAndLoadDocument(taskId) |
| WakeUp Service (финальная версия) | Передача кода Разработчику 1 на 15-16 неделях |

### Разработчик 1 ↔ Разработчик 3

| Что передаётся | Формат |
|----------------|--------|
| API для очереди | GET /v1/1c/pending, POST /v1/1c/update |
| WebSocket-уведомления | WSS :443, JSON: {"event": "NEW_DOCUMENT", "wmshead_rn": 123} |
| Полный документ для 1С | GET /v1/wms/document/{rn} |
