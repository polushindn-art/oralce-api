# Техническое задание
## Изменение кода функциональных клавиш на ТСД ATOL Smart Prime и ATOL Smart Slim Plus

**Дата:** 15.07.2026

### 1. Общее описание
Настройка кодов функциональных клавиш (F1-F4) на терминалах сбора данных ATOL Smart Prime и ATOL Smart Slim Plus для корректной работы WMS-приложения.

### 2. Требование
Изменить коды клавиш в соответствии с таблицей:

| Клавиша | Требуемый код |
|---------|---------------|
| F1      | 131           |
| F2      | 132           |
| F3      | 133           |
| F4      | 134           |

### 3. Задача
3.1. Определить, какое из приложений отвечает за клавиатуру на конкретном устройстве 
(`приложение «Клавиатура»`, `настройки-система-ButtonMap` или приложение `АТОЛ Настройки ОС`).

3.2. Найти раздел настройки программируемых клавиш (F1-F4).

3.3. Установить для каждой клавиши требуемый код согласно таблице.

3.4. Проверить работоспособность после изменения.

### 4. Проверка кодов клавиш
Для проверки правильности установленных кодов используется встроенный экран «Проверка клавиатуры» в программе QShop.

4.1. **Как открыть:**
- Запустить программу QShop.
- Перейти в раздел «Настройки».
- Выбрать пункт «Проверка клавиатуры».

4.2. **Работа экрана:**
- При нажатии любой клавиши на ТСД на экране отображается её код, название и символ.
- Данные обновляются при каждом нажатии.

4.3. **Если пункт «Проверка клавиатуры» отсутствует:**
- Обновить QShop до актуальной версии **1.26.18**.
- После обновления пункт появится в разделе «Настройки».

### 5. Тестирование
5.1. Открыть экран «Проверка клавиатуры» в программе QShop.

5.2. Нажать каждую клавишу F1-F4.

5.3. Убедиться, что на экране отображаются коды: 131, 132, 133, 134 соответственно.

5.4. Нажать «Закрыть» — экран должен закрыться.
