# API для проверки возраста через Цифровой ID MAX

## Эндпоинт

| Параметр    | Значение                                       |
|-------------|------------------------------------------------|
| Метод       | `POST`                                         |
| URL         | `/v1/max/verify/age`                           |
| Полный URL  | `http://oracle-rest-api.ars/v1/max/verify/age` |
| Авторизация | Не требуется                                   |

---

## Запрос

**Заголовки:**

```
Content-Type: application/json
```

**Тело запроса (JSON):**

```json
{
  "sessionId": "https://www.gosuslugi.ru/m5/xxx?p=f"
}
```

**Параметры:**

| Параметр    | Тип    | Обязательный | Описание              |
|-------------|--------|--------------|-----------------------|
| `sessionId` | string | Да           | Строка из QR-кода MAX |

---

## Ответ

**Структура ответа:**

| Поле                        | Тип     | Описание                             |
|-----------------------------|---------|--------------------------------------|
| `success`                   | boolean | Успешность операции                  |
| `message`                   | string  | Сообщение для пользователя           |
| `timestamp`                 | string  | Время запроса                        |
| `data.isAdult`              | boolean | Подтверждение возраста 18+           |
| `data.studentStatus`        | object  | Статус студента (если есть)          |
| `data.largeFamilyStatus`    | object  | Статус многодетной семьи (если есть) |
| `data.pensionerStatus`      | boolean | Статус пенсионера (если есть)        |
| `data.disabledPersonStatus` | object  | Статус инвалида (если есть)          |
| `data.error`                | string  | Текст ошибки (если есть)             |

**Объект `studentStatus`:**

| Поле | Тип | Описание |
|---|---|---|
| `status` | boolean | Является ли студентом |
| `educationForm` | string | Форма обучения |
| `organizationName` | string | Название учебного заведения |

**Объект `largeFamilyStatus`:**

| Поле | Тип | Описание |
|---|---|---|
| `status` | boolean | Есть ли статус многодетной семьи |
| `district` | string | Регион выдачи документа |

**Объект `disabledPersonStatus`:**

| Поле | Тип | Описание |
|---|---|---|
| `status` | boolean | Является ли инвалидом |
| `disabilityGroup` | string | Группа инвалидности |

## Обработка ошибок

### HTTP коды ошибок

| HTTP код | Описание | Действие кассира |
|---|---|---|
| 200 | Успешный запрос | Обработать ответ |
| 400 | Некорректный запрос | Проверить формат `sessionId` |
| 401 | Ошибка авторизации | Обратиться к администратору |
| 404 | Сессия не найдена | Попросить обновить QR-код |
| 429 | Превышен лимит запросов | Подождать 2-3 секунды |
| 500 | Внутренняя ошибка сервера | Попробовать позже |

### Коды ошибок MAX API

| Код ошибки | Описание | Действие для кассира |
|---|---|---|
| `SESSION_EXPIRED` | QR-код устарел | Попросить обновить QR-код (обновляется каждые 30 сек) |
| `SESSION_NOT_FOUND` | QR-код недействителен | Попросить открыть Цифровой ID в MAX |
| `UNAUTHORIZED` | Ошибка авторизации | Обратиться к администратору |
| `RATE_LIMIT_EXCEEDED` | Превышен лимит запросов | Подождать 2-3 секунды |
| `INTERNAL_SERVER_ERROR` | Внутренняя ошибка сервера | Попробовать позже |

## Таблица действий кассира

| Ситуация | Сообщение покупателю | Действие |
|---|---|---|
| `isAdult = true` | «Возраст подтвержден» | Продажа разрешена |
| `isAdult = false` | «Возраст не подтвержден» | Продажа запрещена |
| `error` = «QR-код устарел» | «Обновите QR-код в MAX» | Сканировать заново |
| `error` = «QR-код недействителен» | «Откройте Цифровой ID в MAX» | Сканировать заново |
| `error` = «Превышен лимит запросов» | «Подождите 2-3 секунды» | Повторить сканирование |
| `error` = «Сервис недоступен» | «Попробуйте еще раз» | Повторить через 5-10 секунд |

## Льготные статусы и скидки

| Статус | Поле в ответе | Условие |
|---|---|---|
| Студент | `studentStatus.status = true` | Есть |
| Многодетный | `largeFamilyStatus.status = true` | Есть |
| Пенсионер | `pensionerStatus = true` | Есть |
| Инвалид | `disabledPersonStatus.status = true` | Есть |

---

## Сценарий работы для кассира

1. Покупатель показывает QR-код из MAX
2. Кассир сканирует QR-код, получает `sessionId`
3. Кассовое ПО отправляет запрос
4. Проверка `data.isAdult` — `true` значит продажа разрешена
5. Если есть `data.error` — показать пользователю
6. Проверить льготные статусы и применить скидку

---

## Ограничения

- Срок действия QR-кода: **30 секунд**
- Лимит запросов к API MAX: **30 RPS** (запросов в секунду)
- Срок жизни токена организации: **1 год**
