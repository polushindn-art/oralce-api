# Инструкция для кассира по авторизации покупателя (для юридических лиц)

**Версия:** 1.0  
**Актуально на:** 10.08.2026

---

## Процесс состоит из двух этапов:

**Этап 1. Идентификация** — определение покупателя

**Этап 2. Авторизация** — подтверждение личности через код

---

## Этап 1. Идентификация покупателя

Покупатель может идентифицировать себя одним из способов:

| Способ | Действие кассира |
|--------|------------------|
| **Сервисная карта** | Сканировать карту |
| **Номер телефона** | Ввести номер телефона в систему |

---

## Этап 2. Авторизация (подтверждение личности)

После идентификации система предлагает **3 способа подтверждения**:

| Способ | Описание |
|--------|----------|
| **MAX Бот** | 4-значный код в приложении MAX |
| **СМС** | 4-значный код по SMS |
| **Звонок** | Автоматический звонок с кодом |

---

## Интерфейс на кассе

### Шаг 1. Поиск покупателя

Введите номер телефона в поле **«Телефон»** и нажмите **«ПОИСК»**.

Система отобразит найденных покупателей с этим номером.

---

### Шаг 2. Выбор способа авторизации

Выберите один из способов отправки кода:

| Кнопка | Описание |
|--------|----------|
| **«Отправить код в СМС»** | Код придёт по SMS |
| **«Отправить код в МАХ»** | Код придёт в бот MAX |
| **«Отправить код по ЗВОНКУ»** | Код будет озвучен по телефону |

---

### Шаг 3. Подтверждение

После отправки кода:

1. Покупатель называет код
2. Введите код в поле
3. Нажмите **«Проверить»**

---

## Что означают результаты

### Успешная авторизация

| Что видит кассир | Что делать |
|------------------|------------|
| ✅ «Авторизация успешна» | Покупатель подтвержден |

### Ошибки при авторизации

| Что видит кассир | Что делать |
|------------------|------------|
| ❌ «Код неверный» | Попросить назвать код еще раз |
| ❌ «Код просрочен» | Отправить код заново |
| ❌ «Покупатель не найден» | Проверить данные идентификации |

---

## Памятка для быстрого доступа

### Полный процесс

1. **Идентификация:** карта или номер телефона
2. **Авторизация:** выбрать способ → отправить код → ввести код
3. **Результат:** ✅ Авторизация успешна

### Если код не подходит

1. Проверить код → Если не работает → Отправить новый код

---

## Важно помнить

- ⏱️ **Код действует 5 минут**
- 🔐 **Код одноразовый**
- 🔄 **Если один способ не работает — используйте другой**

---

## Как покупателю зарегистрироваться в боте MAX

Для авторизации через MAX Бот покупателю необходимо предварительно зарегистрироваться:

1. Найти бота в MAX и открыть его  
   (QR-код и ID бота размещены на кассе)
2. Нажать кнопку **«Регистрация»**
3. Нажать **«Поделиться номером»**
4. Подтвердить отправку номера
5. Дождаться сообщения об успешной регистрации
