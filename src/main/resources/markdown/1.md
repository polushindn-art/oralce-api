## 3. База данных Oracle

### 3.1. Таблицы

- `WMSHEAD` — WMS-документы
- `WMSSPEC` — спецификация документа
- `MARK` — коды маркировки
- `MARKLINK` — связи маркировки со спецификацией
- `WMSPICKER` — назначенные пользователи
- `WMS_TO_1C` — очередь для 1С

### 3.2. Партиционирование

`WMSHEAD` по `created_at` ежемесячно, автоматическое создание.

```sql
CREATE TABLE WMSHEAD (
    rn NUMBER PRIMARY KEY,
    created_at TIMESTAMP,
    status VARCHAR2(20),
    data_json JSON
) PARTITION BY RANGE (created_at) INTERVAL (NUMTOYMINTERVAL(1, 'MONTH'));
```

### 3.3. Индексы

```sql
    CREATE INDEX idx_wmshead_status ON WMSHEAD(status) LOCAL;
    CREATE INDEX idx_wmshead_device ON WMSHEAD(device_id) LOCAL;
    CREATE UNIQUE INDEX idx_wmshead_rn ON WMSHEAD(rn) GLOBAL;
    CREATE INDEX idx_wmsto1c_status ON WMS_TO_1C(status) LOCAL;
```
### 3.4. Триггер защиты завершённых документов

```sql
CREATE OR REPLACE TRIGGER trg_wmshead_protect
BEFORE UPDATE ON WMSHEAD
FOR EACH ROW
BEGIN
    IF :OLD.status IN ('COMPLETED', 'FAILED') THEN
        RAISE_APPLICATION_ERROR(-20000, 'Изменение завершённого документа запрещено. RN = ' || :OLD.rn);
    END IF;
END;
```

## 4. REST API

- POST /v1/wms/receive - приём данных от ТСД
- POST /v1/wms/complete - завершение документа
- GET /v1/sync/pull - выгрузка справочников
- GET /v1/1c/pending - для 1С (список PENDING)
- POST /v1/1c/update - для 1С (обновление статуса)

---

## 5. WebSocket

Для ТСД: /ws, порт 443, дуплекс, отправка ACK

Для 1С: уведомление при создании PENDING
Формат: {"event": "NEW_DOCUMENT", "wmshead_rn": 123}
