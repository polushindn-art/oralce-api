# Инструкция по автоматической установке новых версий клиентских приложений 1С:Предприятие

## 1. Ключевой параметр

Поведение управляется параметром `AppAutoInstallLastVersion` в файле `1cestart.cfg`:

| Значение | Описание |
|----------|----------|
| 1 | Автоматическая установка разрешена (значение по умолчанию) |
| 0 | Автоматическая установка запрещена |

Расположение файла `1cestart.cfg`:

| Режим установки  | Путь                               |
|------------------|------------------------------------|
| Для пользователя | %APPDATA%\1C\1cv8\1cestart.cfg     |
| Для компьютера   | %PROGRAMDATA%\1C\1cv8\1cestart.cfg |

## 2. Способ 1: Обновление через веб-сервер (HTTP)

**Важно:** Начиная с версии 8.3.26, обновление тонкого клиента по HTTP работает в "бесшумном" режиме.

**Шаг 1.** Упакуйте дистрибутив тонкого клиента в ZIP-архив.

**Шаг 2.** Разместите ZIP-архив на веб-сервере:
http://1c-server/distr/client-win-64.zip

**Шаг 3.** В конфигурационном файле сервера `conf.cfg` укажите URL:
PublishDistributiveLocationWindows64 = http://1c-server/distr/client-win-64.zip
PublishDistributiveLocationWindows32 = http://1c-server/distr/client-win-32.zip

**Результат:** При несовпадении версий клиент автоматически загрузит и установит обновление.

## 3. Способ 2: Обновление через сетевой каталог

**Шаг 1.** Создайте структуру на сетевом ресурсе:
\\Server\1CDistr\
├── 1cescmn.cfg
└── 8.3.24.100\
└── distr\
└── client-win-64.zip

**Шаг 2.** В файле `1cescmn.cfg` укажите:
DistributiveLocation = \\Server\1CDistr

**Шаг 3.** На клиенте в `1cestart.cfg` установите:
AppAutoInstallLastVersion=1

**Результат:** При запуске программа проверит наличие новой версии и выполнит автоматическую установку.

## 4. Способ 3: Автоматизация через скрипты

**Тихая установка через MSI:**
msiexec /i "\\Server\Share\1CEnterprise.msi" /qn TRANSFORMS=1049.mst LANGUAGES=RU

**Тихая установка через setup.exe:**
setup.exe /S

**Пример PowerShell-скрипта:**

$version = "8.3.24.100"
$installPath = "C:\Program Files\1cv8\$version"
$setupPath = "\\Server\1CDistr\$version\setup.exe"

if (-not (Test-Path $installPath)) {
Start-Process -FilePath $setupPath -ArgumentList "/S" -Wait
Write-Host "Установлена версия $version"
}

## 5. Установка дистрибутивов на сервер

Чтобы клиенты могли обновляться, на веб-сервере установите пакет:

| Файл | Назначение |
|------|------------|
| all-clients-distr-A.B.C.D.exe | Для всех ОС |
| win-mac-clients-distr-A.B.C.D.exe | Для Windows и macOS |

**Команда установки:**
win-mac-clients-distr-8.3.24.100.exe /S

После установки появится папка `distr` в каталоге 1С.

## 6. Проверка успешности

1. Запустите 1С:Предприятие
2. Проверьте версию в диалоге выбора базы
3. Убедитесь, что в `1cestart.cfg` записалась новая версия

## 7. Устранение проблем

| Проблема | Решение |
|----------|---------|
| Обновление не начинается | Проверьте AppAutoInstallLastVersion=1 |
| Ошибка доступа к дистрибутиву | Проверьте права на сетевой каталог/URL |
| Требуются права администратора | Установка "для компьютера" требует прав |
| Обновление зависло | Проверьте наличие Microsoft Visual C++ Redistributable |
