## 1. Цель

Реализовать на платформе 1С:Предприятие 8.3 (версия 8.3.27+):
- WebSocket-клиент для подключения к REST API
- Чтение очереди WMS_TO_1C
- Создание документов в 1С на основе WMS-документов
- Обновление статуса очереди

Важно: Ты не трогаешь бекенд, Android, Openfire.

---

## 2. Технологии

1С: Платформа 8.3.27+, встроенный WebSocket-клиент
БД: Oracle (таблица WMS_TO_1C)

---

## 3. Взаимодействие с Разработчиком 1

Эндпоинты:
GET /v1/1c/pending - получить список ожидающих документов
POST /v1/1c/update - обновить статус

WebSocket-уведомления: WSS :443
Формат: {"event": "NEW_DOCUMENT", "wmshead_rn": 123}

## Формат POST /v1/1c/update:
```json
{
"wmshead_rn": 123,
"status": "PROCESSED",
"onec_doc_number": "П-12345",
"error_message": null
}
```

---

## 4. WebSocket-клиент в 1С

Версия платформы: 8.3.27 и выше
Подключение: WSS :443
Авто-переподключение: да
Fallback: периодический опрос очереди (раз в 5 минут)

---

## 5. Очередь WMS_TO_1C (таблица в Oracle)

Поля:
- rn (NUMBER PK)
- wmshead_rn (NUMBER FK)
- status (PENDING / PROCESSED / FAILED)
- onec_doc_number (VARCHAR2)
- error_message (VARCHAR2)
- created_at (TIMESTAMP)
- processed_at (TIMESTAMP)

Правила:
- Выбираешь записи со статусом PENDING
- После обработки обновляешь статус на PROCESSED или FAILED
- При FAILED заполняешь error_message
- Один документ не обрабатывается дважды (идемпотентность)

---

## 6. Создание документов в 1С

Приёмка -> Приходный ордер
Наборка -> Перемещение / отбор
Перемещение -> Внутреннее перемещение
Списание -> Списание

Данные: шапка из WMSHEAD, строки из WMSSPEC

---

## 7. Критерии готовности

- [ ] WebSocket-клиент подключается к REST API
- [ ] При уведомлении читает PENDING документы
- [ ] Создаёт правильные документы в 1С
- [ ] Обновляет статус очереди на PROCESSED
- [ ] При ошибке обновляет статус на FAILED с сообщением
- [ ] Fallback-опрос очереди работает (раз в 5 минут)
- [ ] Идемпотентность: один документ не обрабатывается дважды
