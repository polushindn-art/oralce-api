## Термины хранения и адресации

| Термин | Определение |
|--------|-------------|
| **Адресное хранение** | Способ организации размещения товаров, при котором каждому месту хранения присваивается адрес или индивидуальный номер. |
| **Адрес системы хранения** | Уникальный идентификатор, присваиваемый каждому месту хранения (стеллажу, ячейке, полке). |
| **Адрес планограммы покупателя** | Адреса, находящиеся непосредственно в торговом зале, предназначенные для размещения товаров, доступных покупателям (витрины, полки, стеллажи). |
| **Адрес планограммы подтоварка** | Верхние уровни стеллажей или скрытые зоны хранения для временного хранения товаров с целью оперативного пополнения адресов планограммы покупателя. |
| **Аллея** | Пространство между двумя рядами стеллажей, состоящее из прохода и самих стеллажей слева и справа, обеспечивающее свободное передвижение покупателей и сотрудников. |
| **Артикул** | Конкретный товар под индивидуальным номером. |
| **Зона торгового зала** | Определенное пространство, характеризующееся общим признаком (вид ассортимента, сервисные, кассовые, входные зоны и т.д.). |
| **Имплантация** | План выкладки товара. |
| **Крос** | Оборудование для кросс-выкладки сопутствующего товара (подвесная металлическая или пластиковая пластина с крючками). |
| **Линейный метр** | Условное обозначение встройки внутри стеллажа (ширина одной полки). |
| **Линейный адрес системы хранения** | Адрес, в котором места хранения на уровне располагаются последовательно одно за другим, доступ осуществляется через первый ряд. |
| **Объекты хранения** | Ячейки, стеллажи, полки или паллеты, которым присваивается уникальный адрес в системе хранения. |
| **Остров** | Подобие подиума из паллет, установленных друг на друга, на которые выкладывается товар. |
| **Переимплантация** | Процесс перекладывания товара с места на место в связи с изменением имплантации. |
| **Периферия** | Стеллажи, расположенные по периметру магазина. |
| **Планограмма магазина** | План-схема размещения всех видов торгового оборудования (стеллажей, полок, витрин, холодильников) в помещении магазина. |
| **Планограмма товара** | План-схема выкладки товара на конкретном торговом оборудовании с указанием адреса размещения. |
| **Правило правой руки** | Принцип мерчандайзинга: большинство покупателей начинают движение по магазину с правой стороны, поэтому там размещают самые популярные товары. |
| **Стеллаж** | Специализированное складское оборудование для хранения грузов, состоящее из металлических стоек, балок и поперечных балок либо многоярусных настилов (полок). |
| **Торговая зона** | Места в торговом зале, доступные покупателю для самостоятельного выбора товаров. |
| **Подтоварка** | Скрытые зоны временного хранения товаров для оперативного пополнения основной торговой зоны. |
| **Уровень хранения** | Место размещения товара на заданной высоте. |
| **Фейс / Фэйсинг** | Количество единиц товара определенной марки, стоящих в первом ряду на полке и визуально доступных покупателю. |
| **TG (торец стеллажа)** | Торец стеллажа, расположенный в начале и в конце аллеи. |
| **TG A** | Торец стеллажа, расположенный в начале от центральной аллеи. |
| **TG B** | Торец стеллажа, расположенный в конце аллеи, ближе к периферии. |
| **P** | Периметр магазина. |
| **С** | Центральная аллея магазина. |
| **R** | Правая сторона аллеи. |
| **L** | Левая сторона аллеи. |
| **PAC** | Низкое оборудование, расположенное островами в магазине. |
| **К** | Клиентская полка. |
| **Z** | Полка подтоварки. |

## Термины логистики и грузоперевозок

| Термин | Определение |
|--------|-------------|
| **ГУ-23** | Акт общей формы в контексте железнодорожного транспорта, служащий основанием для ответственности участников перевозки. |
| **Заказ от поставщика** | Официальное обращение покупателя к поставщику с просьбой поставить определённое количество товаров в оговорённые сроки и на установленных условиях. |
| **Кросс-докинг** | Логистический метод, при котором товары перемещаются от поставщика к покупателю, минуя промежуточное хранение на складе. |
| **Накладная** | Первичный документ, используемый при передаче товарно-материальных ценностей от одного лица другому. |
| **Патерностер** | Вертикальный механический стеллаж элеваторного типа, обеспечивающий компактное хранение и быстрое перемещение грузов. |
| **Перебои** | Отсутствие товара на полке или недостаточное количество для клиента. |
| **Поддон / Паллета** | Конструкция (как правило, деревянная) для совместной транспортировки грузов. |
| **Паллетоместо** | Условная единица хранения, означающая размер и объём места на складе, который занимает одна паллета с грузом (1200×800 мм или 1200×1000 мм). |
| **Рохля** | Гидравлическая тележка для перевозки паллет. |
| **Товарная накладная** | Первичный документ для оформления продажи (отпуска) товарно-материальных ценностей. |
| **Товарно-транспортная накладная** | Документ для учёта движения товаров и расчётов за их перевозку автомобильным транспортом (состоит из товарного и транспортного разделов). |
| **ТН ВЭД** | Товарная номенклатура внешнеэкономической деятельности — кодированный классификатор товаров для таможенных операций. |
| **ТОРГ-2** | Акт о расхождениях в количестве или качестве товара при приёмке (несоответствие данным поставщика). |
| **ТОРГ-12** | Товарная накладная для оформления продажи товаров. |
| **ТОРГ-15** | Акт порчи, боя, лома товарно-материальных ценностей. |
| **ТОРГ-16** | Акт списания товаров, пришедших в негодность или с истекшим сроком годности. |
| **ФИФО (FIFO)** | Метод учёта запасов, при котором первыми списываются товары, поступившие раньше всех. |
| **ЛИФО (LIFO)** | Метод учёта, при котором первыми списываются товары, поступившие позже всех. В РФ запрещён к применению. |
| **Центр клиентского сервиса** | Зона в магазине для приёма и обслуживания клиентов (возврат, доставка, дисконтные карты, подарочные сертификаты, консультации). |
| **ЭТРАН** | Автоматизированная система подготовки и оформления перевозочных документов на железнодорожные грузоперевозки ОАО «РЖД». |
| **ЭТрН** | Электронная транспортная накладная — цифровой документ, подтверждающий факт, условия и стоимость перевозки груза. |
| **ЭТЖН** | Электронная транспортная железнодорожная накладная — цифровой аналог бумажной транспортной накладной для железнодорожных перевозок. |
| **Штриховой код (штрихкод)** | Графическая информация в виде последовательности чёрных и белых полос для считывания техническими средствами. |

## Термины маркировки («Честный ЗНАК»)

| Термин | Определение |
|--------|-------------|
| **«Честный ЗНАК»** | Государственная система маркировки товаров, введённая в России для повышения прозрачности рынка и борьбы с контрафактом. |
| **ГИС МТ** | Государственная информационная система мониторинга товаров — платформа для отслеживания движения товаров на территории России. |
| **ТС ПИоТ** | Техническое средство получения информации о товаре — программный модуль для проверки подлинности и корректности кода маркировки. |
| **CDN-площадка** | Распределенная система серверов для быстрой доставки цифрового контента пользователям. |
| **Статус «РД»** | «Рассмотрение декларации» — товар ещё не зарегистрирован, продажа запрещена. |
| **Код маркировки (КМ)** | Уникальная последовательность символов, состоящая из кода идентификации и кода проверки. |
| **Код идентификации (КИ)** | Уникальный номер экземпляра товара, включающий код товара и индивидуальный серийный номер. |
| **Код проверки** | Последовательность символов, сформированная криптографическим преобразованием кода идентификации для выявления фальсификации. |
| **КИ (UNIT)** | Единица товара (пачка, потребительская упаковка). |
| **КИГУ (GROUP)** | Код идентификации групповой упаковки для объединения нескольких маркированных товаров с одним GTIN. |
| **КИН (SET)** | Код идентификации набора для объединения маркированных товаров с разным GTIN. |
| **КИК (BUNDLE)** | Код идентификации комплекта для товарной группы «Предметы одежды, бельё постельное, столовое, туалетное и кухонное». |
| **КИТУ (BOX)** | Код идентификации транспортной упаковки, объединяющей до 10 000 единиц товара. |
| **Национальный каталог** | Единая база данных маркированных товаров в системе «Честный ЗНАК». |
| **Объёмно-сортовой учёт (ОСУ)** | Учёт общего количества маркированного товара одного вида, а не каждой единицы продукции в отдельности. |
| **АТК** | Агрегированный таможенный код, объединяющий несколько кодов маркировки для таможенных целей. |
